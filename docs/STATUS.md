Сводка для продолжения работы в новом чате или другим человеком. Обновлено: 22.10.2026.

## Где что

| Что | Где |
|---|---|
| Сайт | https://dmk05.ru (Дагестанский медицинский колледж) |
| Админка / редактор | https://dmk05.ru/admin, https://dmk05.ru/edit |

Запуск на сервере — `docker compose`: контейнер `cms-engine` (сайт, наружу не открыт) и `caddy` (порты 80/443, сертификат Let's Encrypt автоматически, редиректы http→https и www→домен). Подробности — [DEPLOY.md](DEPLOY.md).

## Как обновить сайт после изменений в коде

```bash
ssh root@82.148.30.183
cd /opt/dmk
docker compose exec -T cms-engine node scripts/backup-db.js /app/storage/backups/before-update.sqlite
git pull --ff-only
docker compose up -d --build cms-engine
docker compose ps
```

Перед этим изменения коммитятся локально, проходят `npm test` и пушатся в `main`.

## Что сделано

- **Безопасность:** заголовки (CSP, HSTS и др.), лимиты на публичные API, защита от CSRF, проверка загружаемых картинок, блокировка подбора пароля (в базе).
- **Архитектура:** `src/server.js` — точка входа, маршруты в `src/routes/`, логика данных в `src/domain/`. Тесты: `npm test` (71 тест, временная база, без `.env.local`).
- **Редактор `/edit`:** вкладки «Элемент / Страница / SEO», контекстная панель, отмена/повтор и Ctrl+S, предупреждение о несохранённом, чистая вставка из Word, панель форматирования, окно ссылки с выбором страницы, загрузка логотипа и фото, «Выпадающий список», шрифты.
- **SEO:** серверная разметка страниц для поисковиков, один `h1`, карточки — настоящие ссылки, осмысленные описания, `alt`, sitemap/robots, автоверсии статики. Инструкция — [SEO.md](SEO.md).
- **Медиатека и галерея:** все фото в одном месте (`gallery`), фото новостей попадают туда сами; галерея как в телефоне под новостями и на `/fotogalereya`, просмотр во весь экран со свайпами.
- **Прочее:** плашка о cookie, страница `/politika-konfidencialnosti` (пока заглушка, скрыта от поиска), удобные настройки слайдера, мобильная версия (закреплённая шапка, меню с ×, карточки, зоны нажатия).

## Полезно знать

- **Информационные страницы** заполняются один раз скриптом `scripts/fill-info-pages.js` (содержание в `scripts/content/info-pages.js`), дальше правятся в `/edit`. Скрипт меняет только заглушки и отсутствующие страницы; `--dry-run` показывает изменения без записи. На сервере: `docker compose exec -T cms-engine node scripts/fill-info-pages.js`. Сведения с mik05.ru не использовать: это другая организация. Стоимость на странице «Абитуриенту» написана отдельно от страниц специальностей, менять нужно в обоих местах.

- Если сайт не открывается («соединение отклонено»), а снаружи работает — скорее всего, Windows держит в кэше старый адрес домена (`37.228.116.226`, был до переезда). Лечится командой `ipconfig /flushdns`; проверить, что видит система: `[System.Net.Dns]::GetHostAddresses("dmk05.ru")` в PowerShell.
- Страницы кэшируются браузером на 60 секунд: после обновления может понадобиться обновить страницу.
- **Telegram заблокирован с сервера**, поэтому к нему идёт VPN AmneziaWG — только для адресов Telegram, сайт и SSH работают напрямую. Конфиг `/etc/amnezia/amneziawg/awg0.conf` (в нём закрытый ключ, в репозиторий не класть), служба `awg-quick@awg0` (автозапуск). Модуля ядра нет, работает программа `amneziawg-go` (собрана из `/opt/amneziawg-go`). Проверка: `awg show` (строка `latest handshake`), выключить: `systemctl stop awg-quick@awg0`. Если сменить ключ Amnezia — заменить файл, оставив строку `AllowedIPs` с адресами Telegram и удалив строку `DNS`.
- Локальный пароль админки (`admin123` в `.env.local`) относится только к локальной копии; на сервере пароль сменён владельцем.
